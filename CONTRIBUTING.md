# Contributing Notes for Candidates

Please approach this as if you were joining an existing development team and implementing a small product issue.

## Workflow

1. Create a feature branch:

   ```bash
   git checkout -b feature/inspection-recording
   ```

2. Make logical commits as you work.
3. Keep the scope focused on Issue #37.
4. Complete `SUBMISSION.md` before submitting.

## Definition of Done

A submission is considered done when:

- Backend and frontend start successfully.
- Login still works.
- The inspection workflow can be demonstrated.
- Manager and Inspector permissions are enforced by the backend.
- No unnecessary generated files are committed.
- `SUBMISSION.md` is completed.
- `CODE_REVIEW.md` contains brief notes on the legacy code review exercise.

## AI Tools

AI tools are allowed. You remain responsible for all code submitted. Briefly document where AI helped and how you checked or changed the output.
